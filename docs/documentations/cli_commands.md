# CLI Commands: 

This guide gives an overview of all CLI commands that are availible.
The Commands have to be executed in the /src directory

## Admin User Creation

  - change directory to src
  - type in the terminal
    - flask create-admin

## Admin list Command
  
  - change directory to src
  - type in the terminal
    - flask list-admins

## Deleate Admin Account

  - change directory to src
  - type in the terminal
    - flask delete-admin

## Reset all Data (except delete Admin Accounts)

  - change directory to src
  - type in the terminal
    - flask reset-all 

## List all Commands in the Terminal

  - change directory to src
  - type in the terminal
    - flask help
